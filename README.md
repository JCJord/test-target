# Projeto de Testes de Programação

Este repositório contém vários testes de programação, que abordam diferentes desafios, como manipulação de strings, cálculos, e uso de estruturas de dados. Os testes foram implementados em HTML e JavaScript, com o objetivo de demonstrar a lógica e a abordagem de resolução de problemas.

## Desafios Resolvidos

O repositório contém as seguintes pastas, cada uma representando um desafio diferente:

- **teste1**: Resultado soma de loop
- **teste2**: Cálculo da sequência de Fibonacci
- **teste3**: Cálculo de Faturamento diário e cálculos relacionados
- **teste4**: Cálculo de percentuais de faturamento por estado
- **teste5**: Inversão de string (com outro exemplo de implementação)
  
Cada pasta contém um arquivo HTML com o código e o JavaScript necessário para rodar o teste, e a lógica de implementação é explicada brevemente nos arquivos.
